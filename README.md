# 🐍 100 Days of Python

Repository ghi lại quá trình học và thực hành Python theo mô hình **100 ngày**, với các thư mục `Day1` → `Day100` và bài tập/project tương ứng.

## 📂 Cấu trúc

```text
100-Days-of-Python/
├── .github/
├── Day1/
├── Day2/
├── ...
├── Day100/
└── README.md
```

Mỗi `DayN` có thể chứa source code, notebook, video hoặc tài nguyên thực hành tùy nội dung ngày học.

## 🎯 Mục tiêu

- Xây dựng thói quen lập trình Python hằng ngày
- Củng cố Python từ cơ bản đến project thực hành
- Lưu lại tiến độ và sản phẩm theo từng ngày
- Xây dựng nền tảng cho automation, data, AI và backend

## 🛠 Công cụ

- Python 3
- Jupyter Notebook
- VS Code/Python IDE
- Git & GitHub

## ▶️ Học và chạy

Chọn thư mục `DayN`, đọc README/notebook nếu có, sau đó chạy file Python hoặc notebook tương ứng.

> Cấu trúc `Day1` → `Day100` và nội dung bài học được giữ nguyên. Chỉ cập nhật README để mô tả repository chính xác, gọn hơn.
